# Tasks — sdd-reader-bounded-time (issue 1218)

Conventions:

- `UI` = `brain/scripts/ui/`. Every path below is relative to it unless it starts with `brain/` or `openspec/`.
- Strict TDD, runner `node:test`. One file: `node --test <file>`. Everything: `npm test`.
- Each phase is ordered RED (write the failing test, run it, see it fail for the stated reason) then GREEN (smallest code that passes) then REFACTOR (clean up with the suite green). A GREEN task never starts before its RED task has been run and seen to fail.
- Requirement IDs cite `spec.md` (R1218-n). Decision IDs cite `design.md` (D15-D28).
- Phases are sequential unless a task says `parallel`. Phases 5 and 6 are independent of phases 1-4 and of each other except where noted.
