# Proposal — phase-1 exit demonstration on 1.10.0 (#1185)

Show the phase-1 exit of epic #1121 on the published `@logikas/brain@1.10.0`. The target is two freshly recreated consumers: `csrinaldi/brain-test-plainfiles` and `csrinaldi/brain-test-engram`.

The run covers install, `env:init`, the first commit, protection, and the first merge. It then runs the memory chain and #1081's four seams. Every transcript goes in `evidence/`, which is tracked, so the evidence outlives the session. The 1.9.0 run's transcripts were lost with the session scratchpad.
